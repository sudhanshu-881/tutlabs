# Backend Setup Guide

## 🚨 Current Issue: Backend Not Connected

The application is currently not connected to a backend database. This guide will help you set up the required Supabase backend.

## Quick Setup (5 minutes)

### 1. Create Supabase Project
1. Go to [supabase.com](https://supabase.com)
2. Sign in with GitHub/Google
3. Click "New project"
4. Choose your organization
5. Enter project name: `tutlabs-production`
6. Set a strong database password (save it!)
7. Choose a region close to your users
8. Click "Create new project"

### 2. Get API Credentials
1. In your Supabase dashboard, go to **Settings** → **API**
2. Copy these values:
   - **Project URL** (looks like: `https://xyz.supabase.co`)
   - **anon public** key (long string starting with `eyJ...`)

### 3. Set Up Database Tables
1. Go to **SQL Editor** in your Supabase dashboard
2. Click **"+ New query"**
3. Copy and paste the SQL script below
4. Click **"Run"**

```sql
-- 1. PROFILES TABLE
create table public.profiles (
  id uuid not null references auth.users on delete cascade,
  updated_at timestamp with time zone,
  full_name text,
  avatar_url text,
  education text,
  experience text,
  location text,
  active_role text not null default 'student'::text,
  primary key (id),
  constraint full_name_length check (char_length(full_name) >= 3)
);
comment on table public.profiles is 'Public profile information for each user.';
alter table public.profiles enable row level security;

-- 2. TUTORS TABLE
create table public.tutors (
    id bigint generated by default as identity,
    user_id uuid references auth.users on delete set null,
    name text not null,
    subjects text[] not null,
    location text,
    pincodes text[] default '{}',
    availability text,
    bio text,
    rating numeric not null,
    image_url text,
    verified boolean default false,
    created_at timestamp with time zone not null default now(),
    primary key (id)
);
alter table public.tutors enable row level security;

-- 3. STUDENTS TABLE
create table public.students (
    id bigint generated by default as identity,
    user_id uuid references auth.users on delete set null,
    name text not null,
    learning_goals text[] not null,
    location text,
    level text,
    image_url text,
    created_at timestamp with time zone not null default now(),
    primary key (id)
);
alter table public.students enable row level security;

-- 4. FUNCTION TO CREATE A PROFILE ON SIGNUP
create or replace function public.handle_new_user()
returns trigger
language plpgsql
security definer set search_path = public
as $$
begin
  insert into public.profiles (id, full_name, active_role)
  values (new.id, new.raw_user_meta_data->>'full_name', 'student');
  return new;
end;
$$;

-- 5. TRIGGER FOR THE FUNCTION
create trigger on_auth_user_created
  after insert on auth.users
  for each row execute procedure public.handle_new_user();

-- 6. RLS POLICIES
-- Profiles Table Policies
create policy "Public profiles are viewable by everyone."
  on public.profiles for select
  using ( true );

create policy "Users can insert their own profile."
  on public.profiles for insert
  with check ( auth.uid() = id );

create policy "Users can update their own profile."
  on public.profiles for update
  using ( auth.uid() = id );

-- Tutors Table Policies
create policy "Tutors are publicly visible."
  on public.tutors for select
  using (true);

create policy "Users can manage their own tutor row"
  on public.tutors for insert
  with check (auth.uid() = user_id);
create policy "Users can update their own tutor row"
  on public.tutors for update
  using (auth.uid() = user_id);

-- Students Table Policies
create policy "Students are publicly visible."
  on public.students for select
  using (true);

create policy "Users can manage their own student row"
  on public.students for insert
  with check (auth.uid() = user_id);
create policy "Users can update their own student row"
  on public.students for update
  using (auth.uid() = user_id);
```

### 4. Configure Environment Variables
Create a `.env.local` file in your project root:

```bash
# Supabase Configuration
VITE_SUPABASE_URL=https://your-project-id.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key-here

# Contact Email for OpenStreetMap
VITE_CONTACT_EMAIL=your-email@example.com

# Optional: Gemini API Key for AI features
GEMINI_API_KEY=your-gemini-key-here
```

### 5. Test the Connection
1. Start the development server: `npm run dev`
2. Open the app in your browser
3. Check the browser console for any connection errors
4. Try to sign up or view the tutor/student feeds

## Troubleshooting

### Issue: "Database connection is not available"
- **Solution**: Check that your `.env.local` file has the correct Supabase URL and API key

### Issue: "Failed to fetch" errors
- **Solution**: Verify your Supabase project is not paused and is accessible

### Issue: "Row Level Security" errors
- **Solution**: Make sure you ran the complete SQL script above

### Issue: "Table doesn't exist" errors
- **Solution**: Re-run the database setup script in Supabase SQL Editor

## Production Deployment

For production deployment (Vercel, Netlify, etc.), set the same environment variables in your hosting platform's environment variables section.
